# Introduction

🎆 Hanabi is a visual effect (VFX) library for the [Bevy game engine](https://bevy.org). It's provided as a Bevy plugin, and integrates with both the 2D and 3D renderers. It allows artists to author powerful particle-based effects running entirely on GPU, for maximum performance. Hanabi is also fully customizable, enabling complete control over the way particles are spawned, updated, and rendered, through a composable system based on [_modifiers_](modifiers.md).

> [!NOTE]
> In this book, we (ab)use the term _game_ to refer to any application using Bevy and 🎆 Hanabi. Although most applications based on Bevy are in practice games, nothing prevents you from using Bevy and 🎆 Hanabi in a non-game application. We simply use the term _game_ for short to refer to all applications.
